# Student Dropout Analysis Using Tableau

## Project Overview
This project explores student dropout patterns using Tableau and exploratory data analysis techniques. The analysis focuses on identifying demographic, academic, and financial factors that influence student retention within a Portuguese higher education institution.

## Objectives
- Analyse student dropout trends
- Identify key factors influencing dropout rates
- Create visual dashboards and insights
- Provide recommendations to improve student retention

## Tools Used
- Tableau
- Data Analysis
- Data Visualisation
- Exploratory Data Analysis

## Key Insights
- Students with unpaid tuition fees showed higher dropout rates
- Scholarship recipients were more likely to continue their studies
- Certain academic programmes experienced higher dropout levels
- Demographic and financial factors strongly influenced student outcomes
